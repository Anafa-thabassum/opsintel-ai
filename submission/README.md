# Submission package

| File | Purpose |
|---|---|
| `opsintel-ai-pitch-deck.pdf` | Primary pitch deck for upload |
| `opsintel-ai-pitch-deck.pptx` | Editable pitch deck for the live presentation |
| `opsintel-ai-demo.mp4` | Narrated 2:34 demo video, below the three-minute limit |
| `video-narration.txt` | Editable narration used by the demo video |

The demo uses macOS text-to-speech so the repository contains a complete,
reviewable video artifact. Re-record the same script in the team's own voice if
preferred, but preserve the claims and the sub-three-minute duration.

Before submission, upload the video to an accessible location and test the
link in a private browser window. GitHub may display or download the MP4, but a
public video host is usually easier for judges.
